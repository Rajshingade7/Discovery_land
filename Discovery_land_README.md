# Discovery Land

A complete, modern landing page website for Discovery Land — built with a focus on clean design, smooth animations, and a fully responsive layout.

## Features

- Visually appealing hero section
- Multi-section layout with smooth scrolling
- Responsive design for mobile, tablet, and desktop
- Modern UI/UX design principles

## Tech Stack

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling and animations
- **JavaScript** — Interactive elements

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Rajshingade7/Discovery_land.git
   cd Discovery_land
   ```

2. Open `index.html` in your browser.
